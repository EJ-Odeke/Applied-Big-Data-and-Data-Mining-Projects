# Applied Big Data and Data Mining Projects

## Overview

This repository contains end-to-end data analytics and machine learning projects developed using real-world datasets. The projects demonstrate practical applications of big data analytics, data mining, predictive modelling, customer analytics, and business intelligence.

Each project follows a complete analytics workflow, including data exploration, data cleaning, feature engineering, visualization, model development, evaluation, and business recommendations.

---

## Projects

### 1. Online Retail Customer Segmentation

**Objective:**  
Identify customer purchasing patterns and develop meaningful customer segments to support targeted marketing strategies.

**Techniques Used:**
- Data cleaning and preprocessing
- Exploratory data analysis
- RFM customer analysis
- Feature engineering
- K-Means clustering
- Cluster evaluation using Elbow Method and Silhouette Score

**Key Outcomes:**
- Identified customer groups based on purchasing behaviour.
- Generated insights for customer targeting and retention strategies.

---

### 2. Bank Marketing Response Prediction

**Objective:**  
Predict whether customers are likely to subscribe to a term deposit based on demographic information, campaign history, and contact behaviour.

**Techniques Used:**
- Exploratory data analysis
- Categorical encoding
- Feature engineering
- Handling class imbalance
- Logistic Regression
- Random Forest
- XGBoost classification
- Model evaluation using ROC-AUC, F1-score, Precision, and Recall

**Key Outcomes:**
- Compared multiple classification models.
- Identified important factors influencing customer subscription decisions.

---

### 3. Mobile Money Fraud Detection

**Objective:**  
Develop machine learning models to identify potentially fraudulent financial transactions.

**Techniques Used:**
- Transaction data analysis
- Feature engineering
- Log transformation
- Classification modelling
- Imbalanced learning techniques
- Model evaluation

**Models:**
- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost

---

### 4. Bike Sharing Demand Forecasting

**Objective:**  
Forecast bicycle rental demand to support resource allocation, staffing, and operational planning.

**Techniques Used:**
- Time-based analysis
- Feature engineering
- Weather and calendar analysis
- Regression modelling
- Forecast evaluation

**Models:**
- Linear Regression
- Random Forest Regression
- Gradient Boosting Models
